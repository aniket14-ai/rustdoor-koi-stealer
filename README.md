# Cryptocurrency Software Update - Awareness Demo

This repository demonstrates a simulated cybersecurity attack in which a fake software update is used to trick users into providing sensitive cryptocurrency wallet information. The goal of this demo is to raise awareness about social engineering tactics used by cybercriminals, particularly those involved in cryptocurrency theft.

## Demo Overview

- **Fake Software Update**: Users are tricked into downloading a "fake" update.
- **Wallet Information Exfiltration**: Users are asked to enter wallet addresses and private keys into a fake form.
- **Simulated Data Exfiltration**: The form data is "exfiltrated" and logged for demonstration purposes.

## How to Use

1. Clone this repository to your local machine.
2. Open `index.html` in a browser.
3. Follow the on-screen instructions to simulate the fake software update and exfiltration process.

## Educational Purpose

This demo is intended solely for educational purposes to raise awareness about cybersecurity threats targeting cryptocurrency users. Never download software from untrusted sources, and always verify the legitimacy of any update prompts you receive.
